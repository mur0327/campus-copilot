## 축별 지침 (Codex 몫)

### 축 1: 검색 기법 원 논문과 최근 비교

- 02 문서 §1의 기존 항목(Lewis RAG, DPR, BEIR, Cormack RRF, SPLADE)을 원 페이지 재접속으로 재검증한다. RRF `k=60` 표준값이 원 논문 근거인지 재확인한다.
- BM25 원 출처(Robertson 계열 정리 논문 또는 TREC-3 논문)를 추가 확정한다. 마스터가 BM25를 인용할 때 쓸 정본 하나를 권고한다.
- BM25 대 dense 대 hybrid의 최근(2021~2026) 비교 연구 1~3편을 찾아 "단일 우세 없음·상호 보완" 계열 주장의 선행 근거로 쓸 수 있는지 본다.

### 축 4: 미응답·거절·선택적 답변

- 02 문서 §3의 확정 2편(UAEval4RAG ACL 2025, Sufficient Context ICLR 2025)의 서지·핵심 주장 표기를 재검증한다.
- 고전 축을 보강한다: unanswerable QA(SQuAD 2.0 계열)와 selective prediction/QA 원 논문급 1~2편.
- 2025~2026 신간에서 "기대 행동(완전 답변/제한 답변/거절)과 실제 행동 대조" 형태의 평가를 수행한 문헌이 있는지 확인한다. 있으면 신규성 위협 섹션에 보고한다.

### 축 7: 판정 방법론의 타당성

- 본 연구 qrel 절차의 방어 근거가 될 정본을 찾는다: pooled relevance judgment(TREC pooling 관행), 불완전 판정 하 평가(bpref 등), LLM 보조 relevance 판정의 타당성·한계(2023~2026), LLM 초벌 + 사람 검증 하이브리드 판정.
- 각 문헌이 우리 절차(pool 한정 판정, LLM 전량 초벌, 위험 기반 표적 감사, unjudged 시 채점 중단)의 어느 요소를 지지 또는 반박하는지 관계 컬럼에 명시한다.
