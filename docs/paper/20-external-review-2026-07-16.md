## 2. Blocking과 처리 결과

B1: Q008 실제 행동 라벨이 동결 rubric과 충돌.

응답이 확인된 절차를 안내하며 미확인 한계(정정 기간 일자·시스템 조작법)를 명시했으므로 rubric 정의상 qualified_answer인데 full_answer로 집계됐고, fully_correct 판정과도 모순이었다.
처리: 조정본 정정 + revision history 기록 + 공개 산출물 재발행(커밋 `eacbdd4`). 엄격한 종합 성공 30/50 → 31/50(62.0%), 제한 답변 기대 0/3 → 1/3, 과잉답변 14/22 → 13/22(59.1%), Q035 제외 29/49 → 30/49(61.2%). 마스터 수치 16곳 갱신, §8.3의 Q008 실패 사례 서술 삭제.

B2: qrel 감사가 실제보다 독립적으로 서술됨.

`blind human final decision` 표현이 마스터 §15의 용어 통제와도 충돌했고, 원시 차이(표적 67묶음 페이지 43·evidence 34건, 표본 20묶음 7·7건)가 보고되지 않아 최종 변경 3·4·2건만 보면 합의도를 과대 해석할 여지가 있었다.
처리: §5.5를 3단계 절차(LLM 초벌, 초기 라벨 비공개 단일 저자 재판정, 공개 후 조정)와 원시 차이·최종 채택 변경 분리 보고로 재작성. §13.8 문구 교체. §14에서 감사 절차 표를 필수 표로 승격.

## 3. 채택 결정

제목·기여는 리뷰의 수정안 A를 채택해 §1.4와 §1.8에 반영했다.

- 작업 제목: 대학 공식 문서 RAG의 검색·근거·배포 적합성과 응답 정책 감사: 단일 기관 50문항 사례
- 기여 중심을 새 분해 평가법 제안에서 단일 대학 배포 맥락의 통합 감사 사례로 이동.
- §16의 재검토 선행 조건(MTRAG·MTRAGEval 원문 확인)은 이 리뷰의 독립 확인으로 충족.

## 4. 신규성 재검토 요지

- §13.1의 MTRAG(TACL 2025)·MTRAGEval(SemEval 2026) 독해는 원문 대조로 확인됐다. partial 문항을 답변 측으로 묶으므로 본 연구의 정확한 3단계 일치 채점과 다르지만, 3단계 answerability와 기대·실제 대조 자체의 최초성은 주장 불가.
- UAEval4RAG는 부차 항목이 아니라 거절·응답 선택 평가의 핵심 경계선으로 사용.
- 추가 문헌: RAGChecker(arXiv 2408.08067, 미심사, claim-level retrieval·generation 진단이라 포괄적 분리 평가 신규성을 직접 약화), PassiveQA(arXiv 2604.04565, 3행동 QA), SURE-RAG(arXiv 2605.03534, evidence sufficiency 기반 기권). 셋 다 미심사 후보로 §13.9에 반영.
- 동일한 전체 분해(페이지·청크 계보 + 주입 근거/표시 출처 + 시간·대상자 + 정책 일치 + 감사 계보)를 한 기관 행정 RAG에서 수행한 심사 통과 논문은 확인되지 않았다.

## 5. Major 지적 (2026-07-17 마스터 반영 완료)

아래 항목은 전부 마스터 정본에 반영됐다. 집필 시 참조처는 이 목록이 아니라 마스터 본문과 §15 집필 통제다.

용어·해석 재정의:

- C1: 과잉답변을 보수적 응답 정책 불일치로 재정의하고 policy-only mismatch와 substantive failure를 분리. expected_behavior가 연구 정의 정책 라벨임을 명시.
- C5: 엄격한 종합 성공을 사전 정의된 다축 rubric의 결합 준수로 정의. 실사용자 관점 표현 금지.
- I1: 문서 temporal deployability와 응답 주장 temporal validity를 용어로 분리하고 정책 매핑 표 제시.
- I2: 사람 코딩 응답 행동과 시스템 answerability 필드를 구분. 46/50은 후자에만 해당.

범위 한정:

- C2: 질문셋 구성(설문 6/연구자 44, 알려진 실패 포함, 개발 재사용)을 방법 절에 명시하고 모집단 성향 표현 금지.
- C3: 검색 trade-off는 동결 실행의 기술적 관찰로 한정. RRF 기제·인과 서술 금지.
- C4: 축의 분리는 실패 집합의 비동일성으로 한정. claim support와 source display를 별도 열로 먼저 보고.
- C6: 기여 4는 재현성이 아니라 산출물 수준 감사 지원으로 표현. 공개/해시 검증/비공개 범위 구분.
- I3: RQ3 대상을 통제 평가 화면의 응답 텍스트·표시 출처로 고정.
- I4: RQ1(top-5, Best Bets OFF)과 최종 응답(top-6, ON)을 별도 실험으로 서술하고 인과 연결 금지.
- M4: 한 문항 차이·작은 분모(1/3 등)는 절대 건수 병기, 사례 결과로 기술.

방법 절 필수 내용과 기타:

- M1: 기대 행동 정책의 규범적 성격(연구 정의, 기관 승인 아님) 한 문단.
- M3: 실행 조건 표(커밋·지문·모델·top-k·sampling 미고정·공개 범위).
- M5: privacy 축은 양성 사례 0건이라 탐지 성능 미평가로 한정.
- I6: §5.3 사유 목록에 전체 enum 또는 관찰 사유 한정 표기.
- I7: 표본 20건을 파일럿 시간 산출 결과로 쓰지 말고 사전 고정 층화 QC 표본으로 서술(시간 기록 확인 불가).
- I8: EXP-01~06 로그를 현재 수치 근거로 인용 금지하는 통제 문구.
- C8~C10, N2: 배포 맥락 통합 감사를 전면에, 주입 근거/표시 출처 분리 사례(Q002·Q041) 강조, 감사 전후 순위 유지는 제한적 민감도 분석으로 서술.
