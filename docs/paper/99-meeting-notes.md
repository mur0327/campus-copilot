## 7/20 미팅 결과 (원고 1차 피드백)

### 구조 피드백과 반영

- 소절이 너무 세분화되어 책처럼 보임 → 2장·3장 소제목 전부 제거, 연속 산문화.
- 장 제목은 내용을 알 수 있게 → 3장 "평가 대상 학사 안내 RAG 시스템", 5장 "검색 회수와 최종 응답 평가 결과"로 변경.
- 설명이 먼저, 그림이 나중 → Fig. 1을 3장 서술 뒤로 이동.
- 논의·한계가 길며 결론에 포함 가능 → 논의를 "5.4 분석 및 고찰"로, 한계를 "6. 결론 및 한계"로 재배치. 7장 체계에서 6장 체계로.
- 숫자 비교표에 시각 차트 제안 → Table 3 아래 Fig. 3(흑백 묶음 막대) 신설.
- 관련 연구 그림 제안은 지면 비용을 고려해 보류.
- 쪽 나눔 시 제목-내용 분리 금지는 HWPX 조판 단계에서 처리.
- 결론은 서론의 문제 제기가 결과로 이어지는 구조여야 하며, 현행 결론에서 빠진 것은 아님.

- 투고분야: 인공지능 / 머신러닝 / 딥러닝.

- 제목은 내용 확정 후 마지막에 결정. 연구비 표기는 추후.
- 일정: 7/26까지 피드백 반영 원고 송부 → 추가 피드백 → 7/31 투고.

### qrel v3 블라인드 판정

### 판정 중 나온 질문

축 ①인 근거 존재에서 최신성을 제외한 이유를 정리한다.

- 직관적으로는 최신 문서를 보여주는 게 맞다고 느끼는데, 왜 ①에서 제외하나.
- 답(2026-07-13 정리): "낡은 답이 있는 질문"(Q040형, 시간 유효성 검증의 문제)과 "답이 아예 없는 질문"(Q045형, 수집·코퍼스의 문제)을 구분하기 위해서다.
- ①에 최신성을 섞으면 둘 다 "없음"이 되어 고장 위치가 사라진다(v2의 실수, 리뷰 4 치명 1).
- 최신성 직관은 버린 게 아니라 ②(배포 적합성)에 배치했다. "① 있음 + ② 거절(옛날 공지)" 조합 자체가 논문의 발견.
- 이 분리 근거를 v3 판정 기준 문서와 방법 절에 쓴다.

## 7/29 2차 피드백 결과

받아 적은 러프 메모 기준이며, 곧이곧대로가 아니라 아래 해석·결정으로 반영한다(2026-07-29 반영 완료).

- 일정: 투고 마감 1주 연장(7/31 → 8월 첫째 주). 쪽수는 나중에 맞춘다.
- 서론: 너무 길다 → 기여 문단 삭제(신규성 경계 문장은 2장에 이미 중복 존재해 손실 없음), RQ 문단은 4장 도입으로 이동, 구성 문단 압축. 배경 통계로 DEC Global AI Student Survey 2024 인용(신규 [1]).
- 관련 연구: "기존 연구를 서론으로"는 서베이 전체 이동이 아니라 서론에 요약·한계 3~4줄 유지로 해석(전체 이동 시 서론이 다시 길어져 모순). 원리 설명 보강으로 BM25 식 (1)·RRF 식 (2) 추가, 그림은 넣지 않기로 결정. 수식은 5장 해석의 복선(어휘 불일치, 단독 상위 문서의 결합 순위 하락) 역할.
- 3장: 대제목 "시스템 구성 및 실험 환경"(교수님 임시 명칭 "실험 실습" 대체), 3.1 학사 안내 RAG 시스템 / 3.2 실험 환경으로 분리. 도입은 "본 연구에서 구현한 학사 안내 RAG 시스템은~". 문장 연결 다듬기, "끄고/켠" → "비활성화/활성화", "세 검색 구성" → "세 가지 검색 구성". 프로세스 번호 목록화는 산문 연결형 유지로 결정.
- 4장: 도입에 평가 필요성 2문장 + RQ1~3. 4.1과 4.2를 "4.1 평가 질문과 정답표 구성"으로 병합, 질문 설명은 5문장으로 압축(기대 행동 분포 28/3/19, Q011/Q035 중복, 설문 윤리 1문장은 보존; Q021~Q026 번호 나열·Q026 거절 시험 후보·질문 유형 나열은 삭제).
- Table 1 Note: 유지. KMMS 게재 논문(제29권 제6호, 장애인 플레이어 AI 어시스턴트)이 표 아래 "Note." 5회 사용한 선례 확인.
- 인용: DEC 추가와 구조 개편으로 [1]~[31] 등장 순 전체 재부여(스크립트 검증 통과).

### 5~6장 선제 자체 피드백 (2026-07-29, 교수님은 4장까지 열람)

3차 피드백이 5~6장에 집중될 것으로 예상하고 같은 기준을 선적용했다.

- 반영: 5장 도입 로드맵 2문장 추가, Table 3·Fig. 3 참조를 서술 문장으로 전환, "여섯 지표"→"여섯 가지 지표", "세 반복 실행"→"세 번의 반복 실행", "잡아낸"→"각각 드러낸", 5.2 분포 문단 어미 변주, 6장 한계 넷째 문단에 "이 밖에도" 연결.
