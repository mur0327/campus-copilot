# 수정본에서 반영할 것

수정본을 올릴 때 함께 처리한다. 무수정 게재가 나오더라도 투고규정 제11조에 따라 게재용 파일을 다시 제출하므로, 그 단계에서 반드시 반영한다.

## Table 3의 2행과 3행 교체

투고본의 Table 3은 본문보다 앞선 판본이다. 값은 모두 같으나 이름과 합계 표기가 본문과 어긋난다.

| 어긋남 | 투고본 | 본문 서술 |
| --- | --- | --- |
| 감사 규모 | `67 high-risk targets + 20 stratified samples` | `87개 묶음`, `고위험 사례 67개` |
| 2행 결과 | `Raw differences` | `최초 불일치 수` |
| 3행 결과 | `3 page pairs, 4 evidence pairs` | 판정 단위가 라벨과 근거 등급 |

교체할 행은 다음과 같다.

```
| 2. Label-blind human audit | Single author | 87 question-page bundles (67 high-risk cases, 20 stratified samples) | Hidden | Initial mismatches: pages 43, evidence grades 34 (targets); 7 and 7 (samples) |
| 3. Adjudication and full question review | Same author | All differences + all 50 questions | Revealed | Adopted changes: 3 page labels, 4 evidence grades, 2 expected behaviors, 1 secondary reason |
```

1행과 표 제목은 그대로 둔다.

## 확인 결과 이상 없는 항목

투고본과 `21-manuscript.md`를 대조한 결과 아래는 일치한다.

- 본문 문장 227개 중 214개 완전 일치, 나머지는 국문 표현 교체(감사→평가·검토, 망라→포괄, 보고→제시 등)
- 표 1·2·4·5·6 전체, Table 2 각주, 그림 5개
- 표·그림 캡션 11개, REFERENCE 30편, 인용 등장 순서, 결론 3문단
- 모든 수치 토큰

## 게재 확정 후 판단할 것

- 국문 제목이 `배포 적합성 다층 평가`로 바뀌면서 `검색 회수`와 고정 사례 한정이 제목에서 빠졌다. 본문 5장 제목과 RQ1은 검색 회수를 다루므로 최종본에서 제목 범위를 다시 볼 수 있다.
- 국문은 `평가`·`특정 대학`, 영문 초록은 `audit`·`single-institution`으로 갈려 있다. 최종본에서 한쪽에 맞춘다.
- 게재용 조판 기준 8쪽 초과분은 쪽당 5만원이다(투고규정 제13조).
