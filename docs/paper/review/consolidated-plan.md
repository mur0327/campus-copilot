## 대조 결과 요약

세 모델의 지적을 합치면 약 170건이고, 중복을 제거하면 고유 항목 약 120건이다.

리뷰별 성격이 뚜렷하게 달랐다.

- **Gemini 3.6 Flash**: 짧지만 다른 두 리뷰와 겹치는 지적이 많아 교차 검증에 쓸모가 있었다. 인용 오류가 한 건 있었다.

## 이미 반영한 것

- 결론 문단 구조를 3문단으로 복구(Max M1). 정본이 그렇게 적혀 있어서가 아니라, 합쳐진 문단이 한계·한계·산출물·향후의 네 주제를 담아 마지막 인상이 급하게 끝났기 때문이다.
- Table 4와 Fig. 4를 참조 문단 바로 뒤로 이동(Max M2). Table 6은 이미 옮긴 상태여서 같은 장 안에서 규칙 적용이 갈려 있었다.
- 5.3 마지막 문단의 반복 제거(Pro 5.3-P10)와 향후 연구 문장 분할(Pro 6-P9).
- 검증 스크립트에 결론 문단 수와 표·그림 인접성 검사를 추가(`tmp/check-manuscript.py`).

## 반영 계획

### 1단계 — 세 모델 공통 지적 (9건)

가장 신호가 강하고 대부분 문장 분할이라 위험이 낮다.

1. 서론의 `질문, 페이지 및 청크 세 수준의 평가 정답표(qrel)에 ...` 문장을 세 문장으로 분리
2. 서론의 `같은 최종 평가 정답표로 ... 재채점하고, ... 판정하며, ... 진단한다`를 세 문장으로 분리
3. 5.3 반복 일치도 문장을 세 문장으로 분리
4. Best Bets를 첫 등장에서 한 구로 설명
5. pool과 pooled qrel을 2장 첫 등장에서 한 구로 설명
6. 결합 근거 축을 4.2 축 소개에서 정의
7. 3.1의 RRF·관련도·표 청크 세 기능을 세 문장으로 분리
8. 2장의 `원류`, `계보`, `경계` 은유를 평이한 표현으로 교체
9. 영문 초록의 압축 표현 다섯 개 풀어쓰기. 200단어 상한을 지키기 위해 늘린 만큼 줄인다

### 2단계 — 단일 모델 지적 중 값어치가 큰 것

- **5.2의 논리 오류**(Pro): `품질 축을 통과하고도 ... 부분 정확에 그친 사례`에서 내용 정확성도 품질 축이므로 모순이다. `다른 품질 축은 통과했지만`으로 고친다. 세 리뷰 중 유일하게 잡은 실제 오류다.
- **4.2 단계별 마스킹 문장의 중의성**(Pro): `실제 주입 근거와 라벨을 가린 참조 묶음`이 두 가지로 읽힌다. 세 문장으로 나눈다.
- **`근거로 뒷받침되더라도`의 조사**(Gemini): 2026-08-03에 `지지되더라도`를 고치면서 조사를 함께 고치지 않은 누락이다.
- **`원시 차이` → `최초 불일치 수`**(Pro, Gemini 공통).
- **`67묶음`의 단위 불명**(Pro, Max 공통): 뒤에서 `페이지 쌍`, `근거 쌍`이라는 다른 단위도 나와 흔들린다.
- **표 내용을 산문에서 다시 읽어 주는 중복**(Max): Table 5 소개 문장.
- **`45개` → `45문항`, `질문 50개` → `50문항`**(Max): §15.3.2 규칙 15.

### 3단계 — 나머지 문장 다듬기

절별로 수용 판정한 개별 항목이다. 서론 11건, 2장 19건, 3장 12건, 4장 30건, 5장 28건, 6장 6건.

### (가) 판정 축 이름과 산출물 필드의 대응 (9건)

`시간 배포 가능성`, `응답 주장 시간 유효성`, `대상자 적합성`, `표시 출처`, `개인정보`, `판정 후보 pool 내 근거 부재`, `정책 전용 불일치`, `동결 출력 공개본`, `산출물 수준 감사`.

LLM 판정과의 대비 축이 갈리거나 2026-07-25의 용어 확정과 어긋난다.

### (다) 지도교수 확정 결정 (5건)

1~3차 피드백에서 확정한 구조이므로 되돌리지 않는다.

### (라) 범위 한정 문구 삭제 (4건)

`이 사례 안에서`, `이 사례에 한정된다`, 단일 기관 한정의 반복을 줄이라는 제안.
§15.2가 금지하는 범위 없는 일반화가 되고, 외부 리뷰가 지목한 최대 약점의 방어선이다.

### (마) 학회 양식과 표기 방침 (4건)
