# 외부 리뷰 3 — RQ 체계 토론과 사인오프 (2026-07-11 ~ 07-12)

형식이 이전 리뷰(07·09)와 다르다: 일방 리뷰가 아니라 Claude와 GPT의 왕복
토론(4라운드 + 사인오프)이었고, 쟁점마다 수용·반박·데이터 검증을 거쳐
RQ 체계(10~13)를 확정했다. 이 문서는 토론의 정본 요약이다. 최종 반영 결과는
10~13 문서가 정본이고, 여기는 결정의 경위를 남긴다.

참여: Claude(문서 저자·방어), GPT(공격·검증, gpt-5.6-terra 및 사인오프
라운드는 gpt-5.6-sol, effort high), 저자(관전·데이터 실행·최종 결정권).

## 1. 라운드 요약

1라운드(GPT 공격): 7개 지적 — 치명 2(오답변 시도율 9/18의 과잉, 재량 의존의
단일 실행 한계), 중요 4(pooled qrel 낙관 편향, RQ2 배타 단정, 헤드라인 강도
불균등, RQ1 효용 주장), 사소 1(용어 정의).

2라운드(Claude 응수): 5개 수용, 3개 반박 — pooling의 "hybrid 편애" 공격은
발견 모드 데이터로 반박(추가 gold는 주로 dense 발굴), GPT의 "랭킹 실패 없음"
전제는 Q033·Q047로 반박, RQ3 제목의 후퇴 폭 협상 + 반복 실행 카드 제시.

3라운드(GPT 응수): "순환논증" 표현 철회(단 post hoc pooled 명시 요구),
"랭킹 실패 없음" 철회(단 Q033·Q047은 merge_loss가 아니라 저순위·절단임을
정정 — Claude 수용), RQ3 "절반" 반박(분모 3개 어느 것도 절반 아님 — Claude
수용, 숫자 제목으로 교체), 반복 3회 시 인정 수위를 구체 제시.

4라운드(합의 잠금): 조건부 구조 확정 — RQ2 "더 자주"는 재집계표 조건,
RQ3 꼬리는 반복 행동 일치 조건.

## 2. 데이터 검증과 사인오프 (2026-07-12)

- RQ2 조건 충족: qrel v2 전량 재실행에서 BM25 미스 16건 = 후보 풀 미진입 14
  / 저순위·절단 2. 오프라인 재채점도 교차 검증 통과.
- RQ3 조건 충족: 동일 구성 반복 3회에서 질문별 행동 일치 14/16, 거절 총수
  7→6→6, 핵심 거절 6문항 전부 재현.
- GPT 사인오프: 세 판단(더 자주 유지 / 꼬리 부착 / 대표값 1회차) 모두 동의.

사인오프에 딸린 정리 요구 2건(12·13에 반영 완료): ① 12번의 "분포 주장 안
함"과 제목 "더 자주"의 경계를 기술통계 문장으로 명시, ② 반복 실행 서술에서
생성 구성 동일·후처리 파서만 변경을 구분하고 원시 출력 미보존을 교훈으로.

## 3. 심사위원의 마지막 한 방 (GPT 경고, 대비 완료)

가장 강한 잔여 공격은 "pool_miss가 왜 비랭킹인가 — 후보 풀 밖도 결국 1차
검색 점수가 낮았다는 뜻 아닌가"이다. 방어는 정의를 좁히는 것: 비랭킹 계열은
랭킹 무관이 아니라 "고정된 후보 풀 안의 재정렬만으로는 복구할 수 없는 후보
풀 미진입"을 뜻하며, 본문 첫 등장에서 "후보 풀 내부의 순위 조정"으로 풀어
쓴다(12에 반영). 두 번째 공격은 대표값 7/16의 선택적 보고 의심 — 1회차가
반복 계획 이전의 유일한 주 분석 실행이었음을 명시해 방어한다(13에 반영).

## 4. 남긴 교훈

- 데이터 조건부 합의 구조(숫자가 제목을 정한다)가 토론을 감정 없이 끝냈다.
- 반박의 절반은 상대의 사실 오류가 아니라 우리 용어의 부정확성에서 왔다
  (오답변 시도율, 절반, merge_loss). 용어를 정확히 하면 공격면이 줄어든다.
- 모델 출력 비결정성(코드펜스 크래시)은 실험 중 발견된 운영 버그이자 논문
  각주 소재가 됐다 — 구조화 출력 평가에서는 원시 응답을 보존할 것.
