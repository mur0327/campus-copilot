# 외부 리뷰 4: 무맥락 최종 점검과 방향 재정렬 (2026-07-12)

**상태: 역사 자료.**
**작성일 2026-07-12.**

qrel 재설계를 촉발한 외부 리뷰와 당시 결정을 보존하며, 현행 논문 방향과 결과는 `19-paper-master.md`를 따른다.

형식: GPT Pro의 무맥락 리뷰(이전 합의에 참여하지 않은 새 스레드, 커밋 9225e88 + 결과 ZIP 열람) 1회 + 왕복 3회(Claude 의견에 대한 응답, 방향 제안, 의의 정리). 참여: 저자(의뢰·결정), Claude(1차 의견·기록), GPT Pro(리뷰).

결론 요지: 게재 거절급 판정. 수치 계산은 대체로 맞지만 수치가 대표한다고 주장하는 구성개념이 틀렸다. 특히 "insufficient 18건 = 정답 부재"라는 등식이 우리 자신의 EXP-06 판정 기록으로 무너졌다. 리뷰 3까지의 사인오프가 뒤집힌 원인은 합의 참여자가 구성개념을 의심하지 못하는 구조적 한계였고, 무맥락 리뷰가 그 역할을 했다.

이 문서는 지적·왕복·잠긴 결정의 정본 기록이다. 10~13 본문 개정은 qrel v3와 EXP-07 결과 확보 후 일괄 수행한다(저자 결정에 따라 두 번 고치지 않는다).

## 1. 판정 요지

치명 6건:

1. qrel의 insufficient가 실제 정답 부재를 나타내지 않음. EXP-05 재판정은 answerable 미스만 pooling했고 insufficient 18건은 동일 강도로 검증하지 않았는데, EXP-06이 그 안에서 완전지지 응답 4건을 발견. 명백 재검 대상은 Q006·Q015·Q032, 축 선택에 따라 갈리는 것은 Q030·Q040.
2. Hybrid Recall@5 1.00은 primary/secondary 등급을 무시해야 성립. Q025는 primary(2025 졸업학점표)가 top-5 밖이고 2024 secondary로 hit(primary-only면 31/32). Q009는 "본문에 학점표 없음"으로 기록된 진입 페이지(secondary)가 rank 1로 MRR을 올림.
3. 기준선이 순수 비교가 아님. 단일 모드에도 intent boost·제목 boost·notice penalty·dedup 등 공통 후처리가 적용되므로 "BM25 vs dense vs RRF" 알고리즘 귀인 불가. production mode 비교로 불러야 함.
4. RQ2 "더 자주"는 분모를 바꿔가며 만든 주장. 14:2는 BM25-only 미스 16건만의 분포인데 제목은 검색·응답 오류 전체를 주장.
5. RQ3는 명시적 거절 정책 실험이 아님. 프롬프트에 판정 rubric이 없어 7/16은 자발적 거절 횟수이고, 반복 3회 일치(14/16)는 범주 안정성일 뿐 정확성 안정성이 아니며, answerable 32건의 최종 답변 품질은 미측정.
6. 내부 타당성 조합. answerable 32문항의 primary URL은 16개, 학사일정 한 문서가 6문항 담당, Q011=Q035 문장 중복, "2인 판정" 표기는 부정확(실제는 LLM 보조 초벌 + 저자 단독 확정).

중요 8건: 현 nDCG@5는 표준 nDCG가 아님(개명 또는 graded 구현), content_sig 매칭 계약이 "미러" 원칙보다 넓음(현 수치 오탐 0건은 확인), 재실행 변동을 "임베딩 비결정성"으로 단정할 근거 없음(원인 미분리로 서술), "동일 sampling 구성" 표현 불가(generation config 미지정·미기록, smoke run 101811 존재로 "유일한 실행"도 부정확), 13의 후보 문장이 자체 금지어("오답변 시도")를 위반, Q040은 scope가 아니라 시간 유효성(temporal validity) 실패로 독립시켜야 함, 공개 재현 패키지 부재(PII 제거 ZIP + corpus manifest 필요), 관련 연구 정렬 문장이 전부 한 단계씩 과함(Sufficient Context "직접 정렬"→개념적 동기, UAEval4RAG 서론 비판을 실험 결과처럼 인용 금지, 88.4%/49.0%는 특정 구성 한 행).

사소 4건: 05 §6 상태표가 §7과 충돌, 0.44→0.94 개발 궤적이 RQ1 자리에 잔존, 그림은 필수 3 + 선택 1(기준선 막대 삭제), MRR cutoff 명시 필요(최종 top-k 기본 6).

수치 불일치 실물 2건: 11 문서의 hybrid 0.8229/0.8690은 재실행값 0.8177/0.8649로 교체 필요. 12 문서의 "insufficient 18건 유형화 7+5+2+2"는 합 16으로, 게이트 통과 16건의 분포이므로 분모 표기 오류다.

프레임 밖 발견: 결과 JSONL 2건(final-response-20260711-101912, 20260712-061656)에 개인 휴대전화 번호 잔존. 커밋 대상은 아니지만 재현 패키지·supplementary로 나가면 유출. 동시에 "공식 문서의 개인 연락처를 정당한 근거로 간주해 재노출"이라는 운영 위험 사례이기도 하다.

## 2. 왕복 결과

Claude 1차 의견(전면 수용: 치명 1·2·4·6, 중요 전부 / 부분 반박: 치명 5의 rubric 재실험은 시스템 개선이라 관찰 논문 범위 밖 / 부분 수용: 치명 3은 production mode 개명으로 저비용 방어)에 대한 GPT 응답:

- rubric 재실험 요구 철회. 관찰 대상이 배포 구성이므로 구성을 고치면 다른 시스템을 평가하게 된다는 반박 수용. 단 방법 절에 "명시적 거절 판정 rubric이 없는 production prompt에서 관찰한 행동"을 명시.
- Claude의 "동결 해제" 표현 교정: v2는 보존하고 v3를 새 버전으로 발행.
- Claude의 숫자 예상("2/16이나 3/16") 금지: 블라인드 재판정 전 예상치를 어떤 문서에도 기록하지 않는다.
- "답할 수 없음은 질의의 속성이 아니다"는 과잉 일반화. "질의 단독의 속성이 아니라 질의·코퍼스·정책·대상자·시점의 결합 속성"으로 좁힘.
- "7/16은 qrel과 무관하게 참"은 절반만 인정: 운영 사건으로는 참, "적절한 거절 7건"이라는 해석은 qrel 의존. RQ3 제목에 숫자를 박는 방식 폐기.
- PII 사례는 Discussion 재료로 한정(중심 기여로 밀면 N=1 과대 포장 공격).
- qrel 실패 자체는 기여가 아님. 기여가 되는 조건은 명시적 v3 판정 구조 + 사람 중심 재판정 + 이진 라벨과 분해 판정의 결론 차이 정량 비교다.

## 3. 잠긴 결정

2026-07-12 저자 확정을 포함한다.

1. qrel v2는 보존하고 v3를 새로 발행한다. 범위는 50문항 전체다(저자 확정. Q009·Q025 재등급이 어차피 필요하고 "insufficient만 재검증" 역공 차단).
2. insufficient 18건은 저자 외 1인(지도교수)의 블라인드 독립 판정을 받는다. 시트는 시스템이 실제 검색한 문서(hybrid top-5 + EXP-06 근거)를 제시하고 "제시된 근거 기준 판정"임을 논문에 명시한다(저자 확정). 문서마다 호스트네임 기반 출처 유형(대학원/입학처/생활관/특정 학과/전교 공통)을 표기한다. 판정자가 서브도메인 의미를 모르면 대상자 스코프 판정이 저자와의 정보 비대칭으로 왜곡되기 때문이다(저자 지적 2026-07-12). 사실 메타데이터라 블라인드를 깨지 않으며, 논문 프로토콜에도 기술한다.
3. 재판정 전 예상 분모·예상 수치를 어떤 문서에도 쓰지 않는다.
4. 기존 최신 retrieval JSONL을 v3 기준으로 오프라인 재채점한다(primary-only 민감도, full/partial 등급, graded nDCG@5, MRR cutoff 명시). 후보 풀 재진단은 하지 않는다. 14:2는 "v2 시점 BM25-only 미스 16건의 기술통계"로 역사화한다(재실행 불필요).
5. RQ1은 production-mode 비교로 계약을 바꾼다. 표 이름(`*-only production mode`), 방법 절의 공통 후처리 명시, 알고리즘 귀인 문장 삭제(초록·결론 포함).
6. RQ2 제목에서 "더 자주"를 폐기한다.
7. 생성 프롬프트는 고치지 않는다. rubric 부재를 방법 조건으로 명시하고, rubric 추가는 future work.
8. EXP-07을 확정 스코프로 잡는다(저자 확정). qrel v3 이후 현재 production 구성 그대로 50문항 전체 end-to-end 평가. 판정 4축 = 행동(answer/partial/abstain) · 내용 정확성 · 근거 지지 · 배포 적합성(current/stale/audience mismatch/privacy risk). raw 출력과 최종 ChatResponse 모두 보존, prompt hash·model string·provider 기본값 미지정 사실 기록.
9. EXP-06은 "게이트가 누출시킨 근거의 오류 전파 사례 분석"으로 위치를 낮춘다. EXP-07이 최종 성능표.
10. 헤드라인은 검색 회수·근거 지지·배포 적합성·거절 행동의 분리 축으로 다시 쓴다. 확정 문안은 v3·EXP-07 후.

## 4. 새 프레임과 후보 문안

v3 이후 본문 개정에 사용할 목적으로 작성했다.

qrel v3 스키마는 질문 수준과 문서 수준을 분리한다.

- 질문 수준: corpus_support(full/partial/none), deployment_answerability(answer/abstain), reason(absent/ acquisition_failure/personalized/stale/audience_mismatch/ policy_exclusion).
- 문서 수준: support_grade(full/partial/invalid), temporal_validity(current/stale/unknown), audience_scope(match/mismatch/unknown).

실패 감사 3단계(RQ2의 새 골격): 검색 회수 실패(코퍼스·수집, 어휘 불일치, 후보 풀 미진입, 저순위·절단) → 근거 지지 실패(완전/부분/무관/내용 부재/초점 불일치) → 배포 적합성 실패(대상자, 시점·연도, 개인화, 개인정보·공개 적정성, 정책 제외). 어휘는 1단계의 원인, 시간 유효성은 3단계의 원인이므로 같은 층에 나열하지 않는다.

RQ 후보 문안(질문형, 결과 제목은 숫자 확보 후):

- RQ1: 공통 후처리를 유지한 BM25-only·dense-only·hybrid production mode는 유효한 정답 문서의 top-k 회수와 초기 순위에서 어떤 차이를 보이는가. (분량 축소: 표 1 + 사례 2)
- RQ2: 관찰된 오류는 검색 회수, 근거 지지, 배포 적합성 중 어느 단계에서 발생하며, 각 단계에는 어떤 실패 유형이 나타나는가.
- RQ3: 코퍼스 내 근거 부재와 배포상 답변 부적합을 분리했을 때, evidence gate와 최종 생성기의 거절 행동 및 거절 성능 평가는 어떻게 달라지는가. (지표 3개: corpus_support=none에서 게이트 거절률 / deployment=abstain에서 최종 거절률 / deployment=answer에서 정확 답변률· 과잉거절률. v2 수치는 역사 비교표로 병기.)

헤드라인 후보:

> 본 대학 학사 안내 RAG 사례에서 높은 top-k 회수율은 질문에 대한 충분한 근거 또는 배포 적합한 최종 응답을 보장하지 않았다. 검색 회수, 근거 지지, 대상자·시간 유효성, 거절 행동은 별도로 평가해야 했다.

압축형:

> 공식 학사 문서 RAG에서는 문서를 찾는 것, 질문을 답할 수 있는 것, 지금 답해도 되는 것이 서로 다른 문제였다.

제목 후보(교수님 안건, 언제든 변경 가능한 저자 방침):

- GPT안: 대학 학사 안내 RAG 시스템의 오프라인 실패 감사: 검색·근거·거절의 분리 평가
- Claude 중간안(구축 유지): 대학 학사 안내를 위한 공식 문서 기반 RAG 시스템 구축과 검색·근거·거절의 분리 평가

서론 기여 문장 3개 + 조건부 1개, 주장 금지 목록 8개, 독자 takeaway 7개는 GPT 의의 답변(왕복 4)에서 확정했으니 집필 시 원문 참조. 조건부 4번째 기여(이진 qrel vs 분해 qrel 민감도 정량화)는 v2/v3 차이가 선명할 때만 기여 목록에 올린다. 주의 2건: "재사용 가능한 감사 프레임"은 "제안하고 한 사례에 적용"까지만(일반화 검증은 future work), 의의 서술 전체가 v3·EXP-07 완료를 전제로 하므로 완료 전 확정 금지.

- 내부 합의는 문장을 잠그는 데는 강하지만 구성개념을 의심하는 데는 약하다. 확정 딱지가 많아질수록 무맥락 리뷰가 필요하다.
- negative(insufficient) 라벨도 positive qrel만큼 엄격하게 판정해야 한다. 검색 결과를 보고 gold를 보완하는 것만으로는 부족하다.
- 최종 생성 응답 판정은 검색 성능 확인의 마지막 단계가 아니라 평가 라벨 자체의 타당성을 검증하는 도구다. EXP-06이 qrel의 결함을 찾아냈다.
- 근거 충실성은 답변 정확성·시의성·대상자 적합성·공개 적정성을 보장하지 않는다. 출처가 붙었다는 것과 출처를 올바르게 적용했다는 것은 다르다.
