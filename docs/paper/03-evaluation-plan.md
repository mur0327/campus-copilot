# 성능 평가

**상태: 역사 자료.** 초기 평가 계획을 보존하며, 실제 수행한 최종 평가 설계와 결과는 `19-paper-master.md`를 따른다.

## 검색 성능 평가

| 예시 질문 (~100개 필요) | 정답 문서 |
| --- | --- |
| 휴학 신청은 어떻게 하나요? | 휴학·복학 안내 페이지 |
| 장학금 신청 기간은 언제인가요? | 장학 공지 페이지 |
| 졸업학점 기준은 어디서 보나요? | 졸업학점 PDF |
| 증명서는 어디서 발급하나요? | 증명서 발급 안내 페이지 |

| 방식 | 비교 목적 |
| --- | --- |
| BM25 only | 키워드 검색만 사용 |
| Vector only | 의미 검색만 사용 |
| Hybrid | 키워드 + 의미 검색 |
| Hybrid + Freshness | 최신성 점수 추가 |

| 지표 | 보는 것 |
| --- | --- |
| Recall@k | 정답 문서를 가져왔는가 |
| MRR | 정답 문서가 얼마나 위에 나왔는가 |
| nDCG | 관련 문서 순위가 전체적으로 좋은가 |

## 사용자 평가

| 방법 | 설명 |
| --- | --- |
| 기존 방식 | 학교 홈페이지에서 직접 찾기 |
| 제안 방식 | 키오스크/RAG 시스템으로 찾기 |

| 측정 항목 | 예시 |
| --- | --- |
| 탐색 시간 | 정보를 찾는 데 걸린 시간 |
| 성공 여부 | 정답을 찾았는지 |
| 이해도 | 다음 행동을 이해했는지 |
| 만족도 | 사용하기 쉬웠는지 |
| 신뢰도 | 공식 정보라고 느꼈는지 |

## 답변 품질 평가

| 평가 항목 | 의미 |
| --- | --- |
| 정확성 | 답변 내용이 맞는가 |
| 출처 일치성 | 답변이 실제 출처 문서와 연결되는가 |
| 최신성 | 오래된 문서보다 최신 문서를 반영했는가 |
| 절차 완성도 | 단계별 안내가 충분한가 |
| 환각 여부 | 없는 내용을 지어내지 않았는가 |

## 결과 예시

| 검색 방식 | Recall@5 | MRR | nDCG@5 |
| --- | --- | --- | --- |
| BM25 | 0.72 | 0.61 | 0.66 |
| Vector | 0.76 | 0.64 | 0.69 |
| Hybrid | 0.84 | 0.73 | 0.78 |
| Hybrid + Freshness | 0.87 | 0.76 | 0.81 |

## 실험 폴더

```
eval/
├── questions.csv          # 대표 질문, 카테고리, 정답 URL
├── gold_sources.csv       # 질문별 정답 문서/문단
├── retrieval_eval.py      # recall@k, MRR, nDCG
├── answer_eval.py         # faithfulness, citation accuracy
├── conflict_labels.csv    # 충돌 문서 쌍 라벨
└── user_study_form.md     # 사용자 실험 설문지
```
