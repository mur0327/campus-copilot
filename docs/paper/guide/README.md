# 논문 투고 가이드

이 디렉터리는 한국멀티미디어학회 투고 준비에 필요한 내부 체크리스트만 관리합니다.

## 원칙

- 학회가 배포한 규정 전문, 논문 샘플, HWP/PDF 원본은 저장소에 커밋하지 않습니다.
- 공개 저장소에는 직접 정리한 요약, 체크리스트, 작성 계획만 남깁니다.
- 세부 규정과 최신 양식은 반드시 학회 공식 안내와 투고 시스템에서 다시 확인합니다.

## 공식 확인 경로

- 논문투고 시스템: <https://dbpiaone.com/mm/index.do>
- 문의처: 한국멀티미디어학회 논문지 담당자

## 로컬 참고 파일

다음 파일은 로컬 참고용으로만 둘 수 있으며 `.gitignore`에 포함되어 있습니다.

- `01-논문투고안내.md`
- `02-논문투고규정및연구윤리규정.md`
- `03-논문심사규정.md`
- `*.hwp`
- `*.pdf`

원본 문서의 내용이 필요할 때는 로컬 파일 또는 공식 사이트를 확인하고, 논문/문서에는 필요한 범위만 직접 요약해 반영합니다.
