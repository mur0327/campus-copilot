# 한국멀티미디어학회 투고 준비 체크리스트

이 문서는 학회 규정 전문을 복제하지 않고, Campus Copilot 논문 투고 준비에 필요한 작업 항목만 내부용으로 정리한 것입니다. 투고 전 최신 규정은 공식 안내에서 다시 확인해야 합니다.

## 일정

- 목표 투고일: 2026년 7월 31일
- 투고 전 최종 확인: 투고 시스템, 논문 양식, 심사료/게재료, 저자 정보, 연구윤리 항목

## 분량 (2026-07-12 확인)

- 8쪽은 규정 요건이 아니라 지도교수와의 잠정 합의 분량이다.
- 규정상 일반 논문(original article)에는 쪽수 상한이 없다. short article만
  5쪽 이내. 게재료가 8쪽까지 15만원, 9쪽 이상 쪽당 5만원 추가(제13조).
  쪽수는 최종 조판 기준으로 표·그림·참고문헌 포함으로 간주.
- 재료(실험 6건, 표 후보 5~6개)가 8쪽 계획을 넘으므로 편집 결정 필요:
  8쪽 압축 유지 vs 9~10쪽 + 추가 게재료 — 다음 미팅에서 교수님과 확정.
- 편집 방침 초안: 기준선표·거절 2×2는 본문, 발견 모드 표·행동 일치표는
  압축 또는 언급만.

## 그림 후보 (matplotlib + 고해상도 PNG, 라벨은 영어)

- 시스템 파이프라인 다이어그램 (검색/게이트/생성 3역) — 필수, docs/diagram 재활용
- 거절 흐름도: insufficient 18 → 게이트 거절 2 / 통과 16 → 생성 거절 7 / 답변 9 — RQ3 핵심 그림
- EXP-03 유사도 분포 + 문턱선 (answerable vs insufficient 겹침) — "문턱으로 못 가른다"
- (선택) 기준선 비교 막대 — 표로 충분하면 생략

## 논문 구성

- 국문 제목과 영문 제목을 준비합니다.
- 영문 초록을 준비합니다.
- 영문 키워드를 준비합니다.
- 본문은 장/절 번호 체계를 일관되게 맞춥니다.
- 표와 그림의 캡션 형식을 학회 양식에 맞춥니다.
- 참고문헌은 본문 인용 순서와 표기 형식을 맞춥니다.
- 감사의 글, 소속, 저자 정보가 심사용 원고에 노출되지 않아야 하는지 최종 확인합니다.

## Campus Copilot 논문용 필수 산출물

- 연구 문제를 3개 안팎으로 고정합니다.
- 평가 질문 세트를 만듭니다.
- 정답 URL과 정답 문단을 라벨링합니다.
- 검색 성능 지표를 산출합니다.
  - Recall@k
  - MRR
  - nDCG@k
- 비교 기준선을 정리합니다.
  - BM25 only
  - Vector only
  - Hybrid
  - Hybrid + Freshness
- 출처 표시와 근거 부족 처리 사례를 정리합니다.
- 절차형 안내가 필요한 질문을 따로 표시합니다.
- 사용자 평가를 진행할 경우 설문 문항과 측정 항목을 준비합니다.

## 투고 전 확인

- 원고가 학회 양식에 맞는지 확인합니다.
- 본문, 그림, 표, 참고문헌 번호가 서로 맞는지 확인합니다.
- 중복 투고나 중복 게재에 해당하지 않는지 확인합니다.
- 모든 저자가 투고 및 연구윤리 기준에 동의했는지 확인합니다.
- 공개 저장소에 학회 원본 양식이나 규정 전문이 커밋되지 않았는지 확인합니다.
- 실험 결과가 재현 가능한 파일과 함께 정리되어 있는지 확인합니다.

## 저장소에 커밋하지 않을 파일

- 학회 제공 논문 샘플 원본
- HWP/PDF 양식 파일
- 저작권 또는 재배포 권한이 불명확한 외부 자료
