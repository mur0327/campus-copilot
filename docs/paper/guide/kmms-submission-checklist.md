# 한국멀티미디어학회 투고 준비 체크리스트

이 문서는 논문 내용의 현황판이 아니라 투고 직전 확인할 작업만 관리한다. 학회 규정과 양식은 바뀔 수 있으므로 저장된 요약을 최종 근거로 사용하지 않고 공식 안내와 투고 시스템에서 다시 확인한다.

## 일정

- [ ] 목표 투고일 2026-07-31을 기준으로 지도교수 검토와 수정 시간을 확보한다.
- [ ] 투고 마감 시각과 제출 완료 기준을 공식 시스템에서 확인한다.
- [ ] 공동 저자에게 최종 원고와 제출 일정을 공유하고 승인을 받는다.

## 원고 완성

- [ ] 국문·영문 제목을 확정한다.
- [ ] 국문·영문 초록과 영문 키워드를 확정한다.
- [ ] 서론, 관련 연구, 시스템, 평가 방법, 결과, 논의, 한계와 결론을 모두 채운다.
- [ ] 본문의 연구문제, 표·그림과 결론이 서로 같은 범위의 주장을 하는지 확인한다.
- [ ] 모든 수치와 문항 ID를 발행 산출물에서 다시 대조한다.
- [ ] 엄격한 종합 성공을 일반 정확도나 배포 합격률로 잘못 표현하지 않았는지 확인한다.

## 분량과 양식

- [ ] 8쪽을 우선 목표로 편집하고, 넘으면 삭제할 내용과 추가 쪽수 비용을 지도교수와 결정한다.
- [ ] 최신 논문 양식, 용지, 여백, 글꼴, 장·절 번호와 캡션 형식을 확인한다.
- [ ] 표·그림·참고문헌을 포함한 실제 조판 쪽수를 확인한다.
- [ ] 표와 그림이 흑백 또는 축소 인쇄에서도 구분되는지 확인한다.
- [ ] 그림 해상도, 글자 크기와 파일 형식이 최신 지침을 충족하는지 확인한다.

## 인용과 참고문헌

- [ ] 모든 인용을 원 논문 또는 공식 학술 페이지에서 확인한다.
- [ ] 본문 인용과 참고문헌 항목이 양방향으로 일치하는지 확인한다.
- [ ] 저자명, 제목, 학술지·학회, 권·호, 쪽수, 연도와 DOI를 원문과 대조한다.
- [ ] 읽지 않았거나 출처를 확인하지 못한 문헌과 수치를 제거한다.
- [ ] 학회가 요구하는 참고문헌 순서와 표기 형식을 적용한다.

## 연구윤리와 저자 정보

- [ ] 모든 저자가 원고, 저자 순서, 소속과 교신 저자 정보를 승인한다.
- [ ] 중복 투고, 중복 게재와 자기표절 여부를 확인한다.
- [ ] 연구비, 이해상충, 감사의 글과 데이터·코드 공개 문구의 필요 여부를 확인한다.
- [ ] 심사용 원고에서 저자·소속·감사의 글을 가려야 하는지 최신 지침으로 확인한다.
- [ ] LLM 보조 판정과 도구 사용을 어느 범위까지 공개할지 학회 정책과 연구윤리 기준으로 확인한다.

## 재현성과 공개 범위

- [ ] 질문, 최종 평가 정답표, 판정 기준, 검색 점수와 최종 응답 집계의 공개 범위를 확정한다.
- [ ] 공개 산출물의 SHA-256과 본문 수치가 일치하는지 확인한다.
- [ ] 원시 모델 출력, 실제 주입 evidence와 개인정보 가능 정보가 공개 파일에 포함되지 않았는지 확인한다.
- [ ] 저장소에서 재현 명령과 필요한 입력 파일을 찾을 수 있는지 확인한다.
- [ ] 비공개 산출물을 공개 산출물처럼 인용하지 않았는지 확인한다.

## 제출

- [ ] 투고 시스템 계정, 논문 유형과 필수 입력 항목을 확인한다.
- [ ] 심사료·게재료, 초과 쪽수 비용과 결제 방법을 공식 안내에서 확인한다.
- [ ] 원고와 별도 첨부 파일을 시스템에서 미리보기로 확인한다.
- [ ] 제출 뒤 접수 번호, 제출본과 확인 메일을 보관한다.
- [ ] 수정본 제출 절차와 연락처를 기록한다.

## 저장소 제외 항목

- [ ] 학회 규정 전문, 논문 샘플 원본과 HWP·PDF 양식이 커밋되지 않았는지 확인한다.
- [ ] 저작권 또는 재배포 권한이 불명확한 외부 자료가 커밋되지 않았는지 확인한다.
- [ ] 비밀정보, 요청 헤더, 원시 LLM 출력과 개인정보 가능 자료가 커밋되지 않았는지 확인한다.
