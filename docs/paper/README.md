# 논문 준비 문서

**상태: 2026-08-06 한국멀티미디어학회 투고 완료. 심사 결과 대기.**
**작성일 2026-07-10, 최종 갱신 2026-08-06.**

이 디렉터리는 Campus Copilot 논문의 연구 설계, 실험 근거, 리뷰와 집필 자료를 관리한다. 논문 방향은 지도교수와 2026-07-10에 합의했고, 제목과 연구문제, 기여 문구는 외부 리뷰와 지도교수 검토를 거쳐 확정했다.

## 현행 정본

논문의 목적, 연구문제, 방법, 결과, 해석, 한계와 작업 목록은 [19-paper-master.md](19-paper-master.md) 한 문서를 현행 정본으로 사용한다. 처음 읽거나 원고를 작성할 때는 이 문서만 먼저 보고, 수치나 계보를 확인할 때만 정본 마지막의 근거 목록을 따라간다. 과거 문서가 정본과 충돌하면 정본을 우선하며, 새로운 결정은 과거 문서가 아니라 정본에 반영한다.

투고한 원고 본문은 [21-manuscript.md](21-manuscript.md)다. 산문은 동결 상태이며, 심사 결과가 오기 전에는 문장을 다시 다듬지 않는다.

마크다운 형식은 [00-doc-style-guide.md](00-doc-style-guide.md)를 따른다. 다만 원고는 학회 양식을 우선하므로 이 규칙의 적용 대상이 아니다.

## 문서 역할

- `19-paper-master.md`: 유일한 현행 집필 정본이자 논문 전체 설명서다.
- `21-manuscript.md`: 투고한 원고이며, 투고본과 어긋나는 부분은 문서 상단에 적혀 있다.
- `00-doc-style-guide.md`: `docs/paper/`의 문서 형식 규칙이다.
- `check_manuscript.py`: 원고를 정본 §15.3.2 규칙으로 점검하는 검사기이며 `python3 docs/paper/check_manuscript.py`로 실행한다.
- `04-glossary.md`: 쉬운 설명을 위한 참고 용어집이다.
- `06-experiment-log.md`: 실험 당시 사실과 해석을 시간순으로 보존하는 누적 기록이다.
- `17-qrel-v4-b2-audit-protocol.md`: 최종 평가 정답표의 사람 감사 계약과 실행 기록이다.
- `18-exp-07-answer-evaluation-protocol.md`: 최종 응답 평가의 사전 동결 계약이다.
- `figures/`: 원고가 참조하는 그림 5개의 SVG 원본이다.
- `submission/`: 투고 시스템에 따로 올린 그림 파일과 [수정본 반영 목록](submission/next-revision.md)이다.
- `review/`: 외부 리뷰 원본, 리뷰를 의뢰할 때 보낸 지침과 지적별 수용·기각 판정이다. 심사에서 수정 요구가 오면 이미 판단한 항목인지 여기서 먼저 확인한다.
- `related-work/`: 2026-07-16 관련 연구 재조사의 분담 지시서와 조사자별 결과다. 병합 결과는 정본 §13에 있다.
- `guide/kmms-submission-checklist.md`: 투고 직전 확인할 작업만 모은 체크리스트다.
- `01`~`03`, `05`, `07`~`16`, `20`, `99`: 결정 과정과 외부 리뷰를 보존한 역사 자료다.

## 사용 원칙

역사 자료의 당시 사실, 수치와 외부 리뷰 발언은 삭제하거나 현행 관점으로 소급 수정하지 않는다. 형식과 상태 안내는 정리할 수 있지만, 역사 자료에서 새 결론을 만들거나 현재 정본처럼 보이게 하지 않는다. 실험 원본과 결과는 `eval/`, 세션별 작업 기록은 `docs/sessions/`에서 관리한다.

저자명, 소속과 연락처는 개인정보이므로 저장소에 기록하지 않는다. 원고에는 자리표시자로 두고 투고 파일에만 채운다. 학회가 배포한 규정 전문과 양식 원본도 커밋하지 않는다.

## 남은 일

1. 심사 결과를 기다린다.
2. 수정본이나 게재용 파일을 제출할 때 [submission/next-revision.md](submission/next-revision.md)의 항목을 함께 반영한다.
