# qrel v3 판정 기준 (2026-07-13)

외부 리뷰 4([docs/paper/15](../docs/paper/15-external-review-2026-07-12.md))의 잠긴 결정 1~3을 집행하는 판정 규칙이다.
v2(gold_sources.csv, qrel-adjudication-2026-07-11.md)는 불변 보존하고 v3를 새 파일로 발행한다.
세 판정자(지도교수 블라인드 18건 / Claude 초벌 50건 / 저자 확정)가 같은 규칙으로 판정했음을 논문 방법 절에 기술하기 위한 정본이다.

## 판정 구조

질문 수준 두 축 + 이유:

- corpus_support: full(있음) / partial(일부만) / none(없음)
- deployment_answerability: answer(답변) / abstain(거절)
- reason(거절 시): absent(답 없음) / acquisition_failure(수집 실패) / stale(옛날 공지) / audience_mismatch(특정 대상 전용) / personalized(개인 로그인 정보 필요) / policy_exclusion(정책상 제외)

블라인드 시트의 한글 선택지와 매핑: 있음=full, 일부만=partial, 없음=none, 답변=answer, 거절=abstain.

문서 수준(2단계, answerable 중심 50건 확장 시):

- support_grade: full / partial / invalid
- temporal_validity: current / stale / unknown
- audience_scope: match / mismatch / unknown

## 판정 원칙

**1. 질문 초점 × 문서 쌍으로 판정한다.**

- 문서의 상태가 아니라 질문이 정확히 무엇을 묻는지(위치/내용/일정/자격)에 대해 판정한다.
- 예: Q015 "모집요강은 어디서 확인하나요"는 위치 질문이므로 모집요강 다운로드 페이지가 full support다.
- PDF 본문 미파싱은 내용을 묻는 질문(Q039형)에서만 support를 깎는다.

**2. 축을 분리한다: ①은 내용만, 시기·대상은 ②에서.**

- corpus_support는 문서가 낡았는지, 특정 대상 전용인지를 따지지 않는다.
- 이유: "낡은 답이 있는 질문"(Q040형, 시간 유효성 문제)과 "답이 아예 없는 질문"(Q045형, 수집·코퍼스 문제)을 구분해야 고장 위치가 보인다.
- v2는 이 둘을 한 라벨에 뭉쳐 실패했다(리뷰 4 치명 1).
- 최신성 직관("최신 문서를 보여주는 게 맞다")은 버린 게 아니라 ②의 판정 기준으로 배치한 것이다.

**3. 판정 재료는 시트와 동일하게 고정한다.**

- 시스템이 실제 검색한 문서(hybrid top-5 + EXP-06 근거)의 청크 본문만 근거로 판정한다.
- 제시 재료 기준 판정(post hoc)임을 논문에 명시한다.
- 판정자 간 일치율이 재료 차이가 아니라 판단 차이만 재도록 하기 위함이다.
- 재료 밖 탐색으로 발견한 것은 라벨에 반영하지 않고 노트로만 남긴다.

**4. 판정 시점은 2026-07-13로 고정한다.**

- ②의 "지금"은 이 날짜 기준이다(여름방학, 2026학년도 2학기 준비 시점).
- 예: 2026-1학기 납부 공지는 ①에서는 내용대로, ②에서는 stale.

**5. 대상자 스코프(v2 원칙의 ② 재배치).**

- 특정 학과·단과대학·대학원 전용 내용은 일반 키오스크 사용자 기준 ② abstain(audience_mismatch)이다.
- 전교 공통이며 정확한 상시 게시물은 answer 가능.
- 출처 판단은 서브도메인 기준(시트의 출처 칩과 동일 매핑).

**6. 시한부 공지(v2 원칙의 ② 재배치).**

- v2는 시한부 공지를 gold에서 일괄 불인정했다.
- v3에서 ①은 내용 존재로만 판정하고, 공지의 유효기간 경과는 ②의 stale로 처리한다.

**7. 개인화 정보.**

- 개인 포털(HUIS 등) 로그인이 있어야만 답이 되는 질문은 ② abstain(personalized)이다.
- 공개 안내 페이지로 절차를 답할 수 있으면 answer.

**8. 블라인드 규칙.**

- 저자 측(Claude 초벌 + 저자 확정)이 끝나기 전에는 지도교수 판정 값을 열람하지 않는다.
- 재판정 완료 전 예상 수치·분모를 어떤 문서에도 쓰지 않는다.

**9. 일치율.**

- 18건에 대해 축별 raw agreement를 보고하고 kappa를 참고 병기한다.
- 갈린 문항은 논의 기록을 남기되 최종 결정권은 저자에게 있다.

**10. 중복 문항(Q011=Q035, 전체에서 이 한 쌍)은 각각 독립 판정한다.**

- 중복은 질문셋 확장(20→50) 때 검수 누락으로 생긴 구성 실수다.
- 지금 제거하면 기존 실험 전부(EXP-02~06, 3모드, 반복 3회)와 비교가 깨지므로 질문셋은 불변으로 둔다.
- 논문 데이터셋 절에는 중복 사실만 중립적으로 기술한다(예: "질문셋에는 동일 문항 1쌍이 포함되어 있다"). "실수" 같은 자기 고백 표현은 쓰지 않는다. 사실 공개로 충분하다.
- 중복 제거 시의 지표 변화를 재채점 단계에서 계산해 병기한다.
